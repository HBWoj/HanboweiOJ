# HanboweiOJ

面向青少年信息学奥赛学习的教学型 OJ 系统。首期面向内部学生与教师，使用 C++（GNU++17），以 NOI 大纲知识体系组织学习内容。

## 项目文档
- [产品需求文档](docs/PRD.md)
- [技术架构](docs/ARCHITECTURE.md)
- [开发路线图](docs/ROADMAP.md)

## 产品目标
围绕“知识学习—代码模板—例题讲解—分层练习—在线评测—错题复盘—教师指导”建立完整学习闭环。

## 当前阶段
产品与工程准备、MVP 方案评审。文档中的技术栈为建议方案，需结合实际部署条件确认后再锁定。

## 安全原则
用户提交的程序视为不可信代码，必须由独立、受限的 Runner 执行；不得在 Web/API 服务进程中直接运行。隐藏测试数据不得暴露给学生。
