# HanboweiOJ

**面向中国青少年信息学奥赛学习的教学型 Online Judge。**

HanboweiOJ 不只负责评测程序是否通过，还希望把「课程学习、知识模板、分层练习、自动评测、错题复盘和成长建议」连接成完整学习闭环。

## 产品目标
- 以 CCF NOI 系列竞赛大纲（2025 年修订版）作为课程映射的重要依据，并支持大纲版本追踪。
- 每个知识点提供适龄讲解、前置知识、代码模板、示例、分层练习、常见误区和掌握标准。
- 提供安全隔离的 C++ 在线判题服务和可追溯提交记录。
- 根据真实提交证据整理错题、定位可能的知识漏洞，并用针对性练习帮助学生复习。
- 用积极、具体、诚实的反馈鼓励学生持续学习，不以刷题数量或排名作为唯一目标。

## 目标技术栈（首版方案，实施时通过 ADR 逐项确认）
- Web：Next.js + TypeScript
- API：Python + FastAPI
- 数据：PostgreSQL
- 异步任务与缓存：Redis
- Judge：独立 Worker + 一次性、受限的容器执行环境
- 部署：Docker Compose 起步，后续视负载演进

## 本地开发
具体启动命令将在应用骨架和依赖锁定后补充。不要在尚未配置安全隔离的情况下，把任意用户代码交给 API 进程或宿主机 shell 执行。

## 重要原则
1. 不把学生提交的代码当作可信输入。
2. 题目测试数据、标准答案和隐藏测试点不得发送给浏览器或学生可访问的 API。
3. AI 的错因结论必须区分「已观察事实」与「推测」，不能仅凭一次 WA 给学生贴标签。
4. 课程内容应原创表达；NOI 大纲用于知识点映射和教学规划。未经授权，不复制或公开传播大纲全文、页面图片或其他受版权保护材料。
5. 学生数据默认最小化收集，支持家长/教师管理与必要的数据删除流程。
