# 课程体系与知识点内容规范

- 文档版本：0.1
- 依据：CCF NOI《全国青少年信息学奥林匹克系列竞赛大纲》（2025 年修订版）
- 原则：以大纲做知识覆盖与层级映射，以原创教学内容服务学生学习

## 1. 大纲映射原则
课程分层至少支持：入门级、提高级、NOI 级。

级别关系按递进方式管理：较高级别包含较低级别所需的知识范围。难度系数用于辅助排序，不应被系统直接解释为学生能力或考试预测。

版本元数据必须保留：
- 大纲名称与版本日期
- 来源机构
- 对应文件页码/章节标识
- 本站课程映射审核状态
- 课程内容版本及更新时间

不要把官方大纲 PDF 的全文、整页图片或大段原文复制进代码仓库或教学页面。题目、解释、示例和练习应由本站原创编写；引用官方内容时只保留必要的来源信息，并遵守版权授权要求。

## 3. 每个知识点统一教学模板
1. **知识点定位**：级别、主题、难度、前置知识。
2. **学习目标**：使用「能够……」描述可观察能力。
3. **先修检查**：用少量问题确认前置知识，不给学生贴标签。
4. **直观解释**：从生活例子、图示或小规模数据引入。
5. **核心概念**：准确定义、适用范围和边界条件。
6. **标准模板**：可编译 C++ 代码，明确输入输出和数据范围。
7. **逐段注释**：解释关键语句为什么存在，而不只是翻译语法。
8. **手动模拟**：跟踪变量、下标、状态或递归过程。
9. **例题讲解**：从读题、建模、算法、正确性到复杂度。
10. **分层练习**：基础巩固、迁移应用、综合挑战。
11. **常见误区**：表现、可能原因、如何验证、纠正训练。
12. **掌握标准**：不以单题 AC 作为唯一标准。
13. **复习入口**：关联的旧知识与后续知识。

## 4. 小学五年级起步的教学路径
小学五年级只是教学节奏的参考，不应成为刚性年龄限制。建议先做诊断，再按能力跳过已掌握内容。

### 阶段 A：计算机与编程入门
- 输入、输出、变量、常量、基本数据类型。
- 算术表达式、比较、逻辑表达式。
- 顺序结构、分支结构、循环结构。
- 简单问题分解、手工模拟和测试样例。

### 阶段 B：C++ 基础能力
- 字符、字符串、类型转换。
- 一维数组、二维数组。
- 函数、参数、返回值、作用域。
- 结构体、排序基础、查找基础。
- 计数、最大最小值、前缀和等基础技巧。

### 阶段 C：基础数据结构与算法思维
- 递归思想、枚举、模拟。
- 栈、队列、链表等适龄基础内容。
- 二分查找、简单贪心、基础图论概念。
- 时间复杂度、空间复杂度和数据范围意识。

### 阶段 D：提高级衔接
- 按经审核的大纲映射补齐数据结构、算法与数学主题。
- 动态规划、树、图、搜索与更复杂算法按先修关系组织。
- 通过专题题单和综合题检验迁移能力。

### 阶段 E：NOI 级拓展
- 以大纲正式知识点为覆盖基准。
- 每个主题由教师审核顺序、先修关系、难度和代表题。
- 不能把所有高级算法一次性堆给初学者；按真实掌握度开放。

以上是教学路径框架，不替代大纲逐条映射。正式课程目录必须由课程维护者逐项核对官方版本后发布。

## 5. 掌握度规则
可先采用五级状态：
- not_started：尚未学习
- learning：正在学习
- practiced：完成基础练习
- proficient：在不同题型中稳定应用
- transferred：能在综合问题中迁移应用

状态由多项证据共同决定，例如：不同题型表现、间隔复习结果、独立完成情况和教师确认。不得仅用一次 AC 或总提交次数推断熟练程度。

## 6. 正向反馈规范
- 反馈针对策略、过程和下一步行动，不评价孩子的智力、性格或价值。
- 指出具体进步，例如「你现在能正确处理循环终止条件」。
- 对困难提供一个可完成的小目标。
- 不用羞辱、恐吓、攀比或连续打卡压力驱动学习。
